☕ Brewed

A simple and modern website for exploring and introducing different types of hot and cold beverages.

This project was created as a front-end web development project with a focus on clean structure, visual design, responsive layouts, and an enjoyable browsing experience.

🌐 Live Demo

"View the Live Website" (https://nafasgh8989.github.io/web-pack-solo-project/)

📖 About The Project

Brewed is a beverage-themed website designed to introduce different types of drinks, including both hot and cold beverages.

The website uses a clean and warm visual style inspired by coffee shops and beverage menus. Each section is designed to make browsing different drinks simple and visually appealing.

✨ Features

- ☕ Hot beverage section
- 🧊 Cold beverage section
- 🥤 Different beverage cards
- 🎨 Clean and modern visual design
- 📱 Responsive layout
- 🌙 Dark Mode theme
- 🌓 Light and Dark theme support
- 🧭 Multi-page website navigation
- 🖼️ Beverage-focused images and visual elements
- 🔗 Navigation between different pages
- 📐 Structured and organized HTML & CSS

🌙 Dark Mode

The website includes a Dark Mode theme designed to provide a comfortable and modern browsing experience in low-light environments.

The Dark Mode is implemented using Tailwind CSS, making it easier to manage colors, backgrounds, text, and other UI elements across different themes.

Dark Mode Features

- 🌙 Modern dark theme
- ☀️ Light theme
- 🌓 Light/Dark theme switching
- 🎨 Theme-specific colors and backgrounds
- 📱 Fully responsive in both themes
- ⚡ Styled with Tailwind CSS

🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- Flexbox
- Responsive Design
- Git & GitHub
- GitHub Pages

📱 Responsive Design

The website is designed to adapt to different screen sizes, including:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

Responsive layouts were implemented using CSS media queries, Flexbox, and responsive utility classes.
